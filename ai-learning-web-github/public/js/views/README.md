# AI Learning Web — Tim AFARZIYA

Web Pembelajaran Informatika — Mata Kuliah Kecerdasan Buatan (AI)
Mata Kuliah IMK · Semester Genap 2026/2027 · Institut Teknologi Indonesia

## Cara Menjalankan

```bash
npm install
npm start
```

Buka `http://localhost:3000` di browser. Gunakan alamat email dan password
minimal 4 karakter untuk masuk; autentikasi ini hanya simulasi sisi klien dan
tidak memverifikasi akun kampus. Progress pembelajaran disimpan oleh server
serta dicadangkan di `localStorage` browser.
